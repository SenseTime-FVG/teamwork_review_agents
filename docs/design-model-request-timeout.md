# 模型请求超时与运行超时分离

MR !141 的第 15 轮模型请求连续 300 秒无进展后，被运行级看门狗直接取消，未进入请求回退；外层终态日志又被显示成总时限超时。

## 行为

- 模型推理和压缩请求使用相同请求级监督器，覆盖 Provider 排队、客户端准备、HTTP 等待和响应读取。
- 无进展期限沿用 Agent 的 idle 配置。每个请求另有固定最长耗时：Codex 沿用 Agent timeout，外部 Provider 取 Agent 与 Provider timeout 的较小值。真实响应事件续期 idle，不续期总期限；日志和退避不是响应进展。
- 请求期间有界暂停外层 idle 判断，管理员取消、父任务终止及已有子任务/诊断总时限继续有效。工具执行仍由原看门狗保护。
- 请求超时优先按现有顺序切换备用候选；无备用可用时，同一轮最多额外重试一次。候选耗尽则返回不可自动重跑的请求超时结果，不创建新会话重放工具。
- 已完成工具结果保留；未完成模型响应中的工具调用不执行。压缩失败保留原始上下文。
- 日志记录请求轮次、阶段、尝试号、耗时、无进展时长及安全的 HTTP 状态/请求 ID，不记录请求正文、凭据或推理内容。
- 新运行的停止终态收尾后统一写入一次。UI 按错误码区分无进展、请求、CI 等待和总时限超时；旧运行的底层停止与终态汇总合并显示，两条历史原始记录仍可查看。

## 验证

使用本地替身验证静默超时回退、历史与工具结果不重放、候选耗尽、单候选重试、排队有界、流式进展、固定请求期限、取消、压缩与工具超时边界；检查旧超时日志展示。真实模型和 MR 不作为回归测试目标。
