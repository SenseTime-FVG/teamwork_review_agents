# 工具结果完整返回与按需补读

## 目标

取消默认 4096 字节首尾截断。普通结果原样（脱敏后）进入当前模型回合，长对话继续通过已有上下文摘要管理。大结果不丢弃，而是保存到本次运行已授权的临时目录，模型通过现有 execute_command 分段读取，不新增工具。

## 策略

- `tool_output_inline_bytes` 默认 65536，表示正文返回阈值，不是内容丢弃上限；旧 `tool_output_tokens` 接受但忽略，不能把旧 4096 值带回新策略。
- 同时检查当前模型输入窗口扣除固定指令、原始任务、工具定义、本轮调用结构及输出预留后的空间。仅整体历史变长时优先走原有压缩，不因为历史暂时占满就截短普通输出。
- 超过正文阈值或单次结果无法装入窗口时，完整脱敏 JSON 写入 `codex_runtime_directory/tool-results` 的随机独占文件，返回绝对路径、字节数、SHA-256、退出码等元数据、首尾预览与补读提示。预览明确不是完整证据，也不是模型摘要。
- 文件仅在当前运行生命周期有效，随既有临时运行目录清理，不污染 Git 工作区，也不扩大到整个临时目录的访问权限。运行结束后的 UI 历史不能承诺临时文件仍可读取。
- 后续历史摘要必须保留尚需补读的文件引用。不要求重跑有副作用的原命令。
- 命令捕获不再静默丢弃 1MB 后的输出。为防止无限输出消耗内存和磁盘，单次捕获设置 16MiB 保护上限；触顶终止命令并明确报告不完整、不可自动重试，不伪称存在完整文件。运行级文件总预算为 256MiB，耗尽或保存失败也明确停止，不自动重跑工具。
- 文件写入前统一脱敏；目录拒绝符号链接，文件名不使用不可信 call_id，独占创建、限制权限，失败文件移除。

## 验证

覆盖 5628 字节完整送模、中文/JSON 转义、多协议公共入口、旧配置迁移、小模型窗口、文件完整性与分段补读、只读 Agent 的运行目录授权、失败/取消后的清理、磁盘错误、捕获超 1MB、16MiB 保护和不重放工具。UI 明确区分文件保存与上下文摘要压缩。
