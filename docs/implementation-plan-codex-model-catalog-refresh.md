# Codex 模型目录刷新实施计划

1. 增加同一 App Server 内的配置与分页模型目录读取，保证超时、失败和取消均清理进程。
2. 运行时接口优先使用该目录，扩充来源、查询时间、失败回退提示，并禁止 HTTP 缓存。
3. 前端增加统一刷新协调器、自动刷新入口与手动按钮，保留模型值和配置草稿。
4. 补充分页、空目录、错误回退、字段脱敏、并发及 UI 接线回归测试。
5. 执行后端与前端测试、构建静态资源，检查完整变更后提交并推送当前分支。
