# 仅审核直接发布结论实施方案

1. 按现有 `REVIEW_AUTO_MERGE` 分支区分远端 CI 等待策略，同步操作模式、可合并状态、结论状态机、评论格式、最终条件与结束流程。
2. 仅审核模式保留完整审核和源目标 SHA 校验，允许当前源 CI 运行中时直接发布最终代码结论，准确报告平台门禁状态。
3. 共享运行时说明限定在确需等待的任务中使用 CI 等待工具，避免覆盖仅审核不等待规则；不改工具执行逻辑。
4. 使用现有模板、Prompt 预览和真实执行输入的回归覆盖显式仅审核及默认模式，同时验证自动合并仍等待 CI，失败阻断和 SHA 保护不变。
5. 必要验证通过后提交、推送，待后台任务空闲后重启；只读检查实际 Prompt 输入，不在真实 MR 发布测试评论或重新启动审核。
