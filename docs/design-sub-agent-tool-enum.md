# 子 Agent 工具参数枚举

当前 `invoke_agent` 只说明必须使用允许名单中的名称，但没有把名单提供给模型。模型可能因此把调用前校验视为无法完成，主动停止任务。

在工具定义中提供 `agent_name.enum`：按父 Agent 的 `allowed_sub_agents` 顺序去重，并只保留当前配置中存在的 Agent。工具说明明确枚举由后台配置提供，无需另外查询名单；调用仍执行后端权限、调用环、深度和额度校验。没有候选时不展示调用工具，不生成空枚举。

内嵌模型与完整 CLI 的 MCP 工具目录使用同一规则。沙盒代理通过现有鉴权通道读取宿主生成的工具目录，不读取配置或接收凭据。查询失败返回工具目录错误，不回退到没有约束的调用定义。只调整工具目录，不向 Prompt 新增身份或名单，也不变更业务结果状态。
