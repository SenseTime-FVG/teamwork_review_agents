# 托管评论模型签名实施方案

## 配置与管理界面

- 为 `AgentConfig` 和前端 `Agent` 类型增加 `managed_comment_model_signature`，默认关闭并保持旧配置兼容。
- 在托管评论配置区增加独立开关；托管评论关闭时禁用操作但不清除已经保存的值。
- 更新配置示例和 README，说明签名来源、显示格式及 CI 评论不受影响。

## 服务端

- 在 Agent 托管评论发布入口根据可信 `run_id` 读取本轮 `model_snapshot`。
- 将模型与有效推理强度格式化为单行安全文本；缺少具体模型时使用明确的账号默认提示。
- 在调用通用托管评论服务前追加统一 Markdown 尾注，使签名参与长度限制、内容哈希、更新和重建逻辑。
- 不修改 Agent Prompt、`publish_comment` 工具参数和 Preflight 评论路径。

## 验证

- 验证配置默认值及显式启用值能正确加载。
- 验证明确模型与推理强度、无推理强度及缺少模型快照时的签名格式。
- 验证服务端使用当前运行快照并把签名写入远端评论；关闭开关时正文保持原样。
- 验证目标分支更新、源版本追加、远端删除重建和 60 KiB 限制不回归。
- 执行 Python 定向及全量测试、前端生产构建、编译检查和补丁检查；验证通过后生成规范提交并自动推送当前分支。

## 签名语言扩展

1. 在后端配置、前端类型和新 Agent 默认值中增加 `managed_comment_model_signature_language`，支持 `zh`、`en`、`bilingual`，未设置默认中文；不增加或修改语言环境变量。
2. 将签名配置传入服务端拼接函数，分别选择中文、英文或双语前缀及未知模型提示，保留运行快照来源、Markdown 处理、空正文、长度限制与托管评论生命周期。
3. 在现有签名开关旁复用自定义下拉框，只有「中文 / English / 双语」三个选项，无可见辅助文案；关闭开关时禁用且保留选项。
4. 补充配置加载及 API 保存回读、签名三种语言、开关关闭、未知模型和前端控件接线测试；同步示例、README 并重建静态产物。
5. 执行专项与完整测试，记录并区分既有失败；只提交当前变更并推送，不重启真实服务，不发布真实平台评论。

## 签名语言验证结果

- 签名、语言配置及保存回读专项测试 27 项通过；前端测试 56 项通过。
- TypeScript 检查、前端生产构建、静态产物引用和入口检查通过；构建保留已有的大包提示。
- Python 完整回归 1290 项通过、8 项跳过，两个既有失败仍是子 Agent 名称变量重命名后旧测试未同步：`test_combined_update_prompts_support_github_and_gitlab`、`test_builtin_prompts_render_configured_environment_values_directly`。
- 三种语言均验证实际运行快照、未知模型提示、模型文本转义、关闭签名保持正文、空正文以及签名计入 60 KiB 限制；未发布真实平台评论或重启服务。
