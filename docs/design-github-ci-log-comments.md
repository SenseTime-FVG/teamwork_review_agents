# GitHub 本地 CI 报告与完整日志

GitHub 的本地 CI 状态不再引用管理员后台地址。终态先回写，暂用关联 PR 的平台地址；独立日志队列随后发布完整日志目录，并把状态入口补为 PR 内的报告评论。失败时优先定位已有失败报告，目录和诊断互相保留入口；关闭失败评论时仍可查看日志目录。

完整运行记录沿用 GitLab 的导出与跨块凭据脱敏，以转义后的 UTF-8 字节数分成有界、可折叠的评论，目录提供每段链接。评论按运行 ID、执行尝试与分段序号托管，部分发布失败后可恢复，不因重试追加已有分段。目录超过单条限制时分组。所有链接来自 GitHub 评论 API 的原生地址，保留仓库访问控制。

传输继续使用持久化后台队列、资源租约和有限重试。旧 Head、旧运行及旧执行尝试不能补写最新状态或重建活动失败评论。GitLab 仍上传原项目附件；日志发布失败不改写真实 CI 结果，不回退到管理后台链接。已发布的分段和目录作为运行记录保留，活动失败摘要沿用成功后清理的规则。
