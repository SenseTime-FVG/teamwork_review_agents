# Windows curl 自动准备实施方案

1. 增加固定分发清单、安全下载、ZIP 校验与原子缓存发布，支持离线同名 ZIP。
2. 增加服务级后台准备管理器及原生禁网版本探针；对接启动、配置变化、关闭、状态和重试 API。
3. 运行级候选发现增加已校验项目缓存，不在 Agent 内下载；明确区分程序就绪和 HTTPS 可达性。
4. 全局设置展示自动准备状态与重试入口，手动路径作为高级项，可恢复运行日志改为告警。
5. 添加下载/完整性/离线/并发/取消/生命周期/API/展示回归，更新部署文档并验证三平台 CI。
