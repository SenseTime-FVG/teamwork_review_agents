# 模型上游事件后回退实施方案

1. 移除模型运行器中“收到任意流式事件后禁止回退”的条件。
2. 保留现有错误分类，只让临时上游故障进入备用模型链。
3. 用独立状态记录是否实际完成候选切换，修正 `fallback_used` 的含义。
4. 扩展模型 Provider 回退测试，模拟先收到 `response.created`、随后发生可回退错误的场景。
5. 验证备用 Provider 能完成同一模型循环、产生 `model.fallback` 日志，并确保失败记录产生时尚未误报已回退。
6. 执行模型运行定向测试、Python 全量测试、编译检查和补丁格式检查。

验收结果以测试通过、模型快照语义准确以及实际回退日志存在为准。
