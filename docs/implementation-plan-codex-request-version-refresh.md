# Codex 请求版本刷新实施计划

1. 移除版本函数的进程级缓存，将版本探测移到每次新模型请求的线程任务。
2. 将探测结果显式传入 SSE 请求与请求头构造，保持重试期间版本一致。
3. 对版本探测失败返回结构化本地错误，保留可执行文件发现错误类别。
4. 补充版本更新、重试、事件循环响应及探测失败回归；调整既有 HTTP 模拟测试，禁止依赖宿主 CLI。
5. 执行相关与全量后端验证，检查完整变更，提交并推送当前分支。
6. 检查后台活跃任务；空闲时重启以加载修复，并验证当前模型连接。若仍有活跃任务则保留服务，不强制重启。

- 提交前后台无活跃 Agent、Preflight 或事件处理任务；不重跑历史失败事件，不修改模型目录和已保存配置。
