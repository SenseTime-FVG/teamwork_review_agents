# Prompt 输出语言配置实施计划

1. 新增统一语言过滤器，并复用现有 Prompt 渲染与错误处理通道。
2. 修改四份版本控制中的 Prompt 及两份本地独立入口模板，统一章节和语言引用。
3. 在 README 中说明变量映射、优先级、支持值和 Prompt 暴露要求；更新示例配置中的全局语言示例与 Agent 级覆盖示例，不默认写入覆盖值。
4. 增加模板、过滤器、环境解析及管理 API 预览测试；本地独立入口仅在存在时参与测试，不让干净检出的测试依赖 Git 忽略文件。
5. 运行针对性测试和完整测试，检查已有改动与本次变更的边界；如既有未提交改动导致回归，单独记录并验证仅含本次差异的提交内容。
6. 仅提交语言相关文件和差异并推送当前分支，不重启实际服务，不修改真实运行配置。

## 扩展任意语言文本

1. 将字典改为别名映射：已知中英文别名继续规范化，其他非空字符串去除首尾空白后原样输出；不改变变量优先级和空值回退。
2. 替换拒绝未知语言的测试，补充自定义语言覆盖全局、保留大小写、普通文本不二次渲染及预览/执行一致测试；保留非字符串类型校验。
3. 同步 README 与示例配置，明确语言不限于中英文，不修改各 Prompt 的章节和调用方式。
4. 完成针对性和完整回归后，仅提交本次文件并推送；不重启实际服务。
