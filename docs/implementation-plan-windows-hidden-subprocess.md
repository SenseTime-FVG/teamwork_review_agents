# Windows 隐藏子进程实施方案

1. 在公共进程控制模块增加窗口参数，区分普通子进程与脱离控制台的服务进程。
2. 补齐工作区快照的两处 Git 调用，以及版本、模型目录、模型客户端与沙盒诊断的四处调用。
3. 添加平台参数、同步调用覆盖、创建策略检查和 Windows 原生无控制台管道测试；纳入 Windows CI。
4. 执行进程控制、服务启停、工作区、模型工具与全量回归，记录本地环境无法执行的 Windows 专属验收项。
5. 检查变更范围后按既有授权提交并推送，不修改运行中的服务配置或凭据。
