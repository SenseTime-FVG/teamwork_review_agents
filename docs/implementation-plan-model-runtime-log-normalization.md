# 模型基座运行日志语义统一实施方案

1. 调整模型基座 SSE 回调，只记录安全诊断副本，不再把 `response.*` 逐条写入运行日志。
2. 为模型基座逻辑会话增加单次创建保护，多轮工具循环只产生一个 `thread.started`。
3. 把每个 Responses `message` 完成事件实时转换为 Agent 消息，并按本轮已转换文本对最终兜底消息去重。
4. 前端消息转换层过滤历史 `response.*` 协议日志，并让运行详情页签使用过滤、合并后的可见消息数量。
5. 增加模型基座多轮工具循环测试，验证工具调用前的中间 Agent 消息能够实时展示、最终 Agent 消息不会重复、协议事件仍保存在结果诊断中且逻辑会话只创建一次。
6. 执行模型运行定向测试、Python 全量测试、Python 编译和补丁检查。
7. 不启动、停止或重启用户服务；仅暂存本次相关文件，验证通过后提交并推送当前分支。

验收标准：模型基座的新运行消息页不再出现 `response.*` 原始卡片；模型每次完成消息输出时立即出现绿色 Agent 消息；最终消息不重复；多轮工具运行只有一个会话创建消息；历史运行重新打开后自动隐藏协议噪声，消息数量与实际可见卡片一致；CLI 模式保持不变。
