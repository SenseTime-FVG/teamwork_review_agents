# 模型基座运行日志语义统一实施方案

1. 调整模型基座 SSE 回调，只记录安全诊断副本，不再把 `response.*` 逐条写入运行日志。
2. 为模型基座逻辑会话增加单次创建保护，多轮工具循环只产生一个 `thread.started`。
3. 保留现有工具开始、工具完成、最终 Agent 消息、用量和错误语义事件。
4. 前端消息转换层过滤历史 `response.*` 协议日志，并让运行详情页签使用过滤、合并后的可见消息数量。
5. 增加模型基座多轮工具循环测试，验证协议事件仍保存在结果诊断中、不会进入运行日志，且逻辑会话只创建一次。
6. 执行模型运行定向测试、Python 全量测试、前端生产构建、Python 编译和补丁检查。
7. 不启动、停止或重启用户服务；仅暂存本次相关文件，验证通过后提交并推送当前分支。

验收标准：模型基座的新运行消息页不再出现 `response.*` 原始卡片；最终输出以绿色 Agent 消息展示；多轮工具运行只有一个会话创建消息；历史运行重新打开后自动隐藏协议噪声，消息数量与实际可见卡片一致；CLI 模式保持不变。
