# 推理 effort 继承值展示

## 范围

全局默认模型、全局回退链和 Agent 回退链不再只显示“跟随 Provider 默认”，而是展示具体 effort 与来源。只修改诊断和界面，不改变执行优先级、模型选择或保存语义。

## 解析规则

- 当前节点显式 effort 优先；继承选项仍显示其下一级解析结果，空值继续表示继承。
- Agent 回退项未指定 effort 时，需要先考虑该 Agent 自己的显式 effort，再考虑当前候选 Provider；全局页面显示未被 Agent 覆盖时的值。
- Provider 的显式 effort 优先于 Codex 运行时配置。外部 Provider 不继承 Codex 配置，无法确定时显示“上游默认（未知）”。
- Codex 基座模式使用用户配置与当前运行器已有的默认值；诊断接口返回相同来源。完整 CLI 模式使用有效配置，再使用所选模型目录的默认 effort。目录缺失时不猜测。
- 完整 CLI 还可能被仓库配置覆盖，运行时兼容降级后的实际值以运行记录为准。

## 展示与验证

已知时显示 `跟随 Provider 默认（high）`，帮助文字显示 `当前有效：high · 来源：…`；Agent 回退继承 Agent 显式值时准确标为 Agent。切换 Provider、模型、执行模式或修改草稿后即时重算，不固化解析值。

回归覆盖显式覆盖、两种 Codex 模式、外部 Provider 隔离、未知/不支持、不同回退候选、动态草稿和配置不变。
