# 本地 CI 磁盘空间等待

磁盘写入失败属于运行环境故障，不能在一秒间隔内耗尽普通事件重试。自动 MR / PR CI 遇到明确的 ENOSPC 时，保存独立的“等待磁盘空间恢复”状态，释放工作区和缓存锁，不启动审核或失败诊断。

- 每 60 秒检查工作区、依赖缓存、数据库和临时目录所在磁盘；至少空出 5 GiB 才恢复。查询失败继续等待。
- 等待和下次检查时间持久化，后台重启后继续；本次资源失败抵消事件与 CI 的普通重试计数。
- 子进程日志出现空间不足时，还需实际磁盘低于阈值，避免将测试里的预期错误文本识别为主机故障；正常断言失败、超时保持原行为。
- 恢复前检查最新扫描快照；已关闭、已换源提交或禁用仓库的等待任务结束，不重放旧版本。
- Dashboard 显示等待原因、各磁盘剩余空间、恢复阈值和下次检查时间。
- 既有已耗尽的错误只迁移仍然打开、源提交仍匹配且明确 ENOSPC 的自动 CI；不重新激活其他历史失败。
- 不自动删除数据；5 GiB 是恢复下限，不是 CI 所需空间的保证。再次不足仍进入等待。

本次覆盖自动事件 CI；独立手动预热运行保留原来的终止和手动重跑方式。
