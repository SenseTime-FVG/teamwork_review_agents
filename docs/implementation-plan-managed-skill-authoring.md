# 受管 Skill 在线新建与编辑实施方案

## 后端

1. 抽取 `SKILL.md` 完整文档解析、字段校验和序列化能力。
2. 新增受管目录边界检查，只允许访问配置文件同级 `skills` 下的直接、非符号链接子目录。
3. 新增受管 Skill 创建、读取和原子更新函数；更新时保留未知 frontmatter 字段和其他目录资源。
4. 扩展 Skill 列表与路径检查结果，返回是否受管、是否可编辑及目录名。
5. 增加创建、读取和更新管理 API，将校验失败统一映射为可读的 422 响应。

## 前端

1. 扩展 Skill API 类型与创建、读取、更新请求函数。
2. 在 Skill 页面增加“新建 Skill”，并保留“配置已有目录”和文件夹导入。
3. 使用右侧抽屉承载配置 ID、名称、描述和 Markdown 操作说明。
4. 创建成功后把受管相对路径加入配置草稿，并刷新已管理目录与元数据。
5. 仅为受管 Skill 提供“编辑内容”；外部路径明确显示只读边界。
6. 在页面文案中解释描述与正文各自用途，以及创建后仍需保存配置引用。

## 测试与验证

1. 单元测试覆盖新建 Skill、正文读取、保留扩展 frontmatter、保留配套资源和原子更新。
2. 安全测试覆盖外部目录、符号链接与非法目录名的编辑拒绝。
3. Web API 测试覆盖创建、读取、更新和错误响应。
4. 执行 Skill 定向测试、Python 编译检查、前端生产构建和 `git diff --check`。
