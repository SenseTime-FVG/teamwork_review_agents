# 运行概览连续选择设计

## 交互范围

“已扫描 MR / PR”和“最近变化事件”两张表分别维护选择起点。普通点击切换单项，Shift 点击将起点与目标之间的可选项统一勾选或取消，包含首尾，不改变区间外的选择。是否取消取决于目标项原先是否已选。

已选记录以稳定 ID 保存，独立于当前页列表。翻页后保持选择状态，返回原页恢复勾选；按钮数量、确认弹窗和提交目标均包含所有页的已选记录，不仅是当前页。仅缓存已选记录，不请求全部数据或全部页面。

选择状态下，复选框所在单元格和紧邻的 MR/PR 标题或事件名称单元格都可点击，包括单元格空白区域。标题此时不跳转仓库或打开详情；其他列、操作按钮仍保留原行为。未进入选择状态时保持原来的详情与外链行为。

## 边界与可访问性

- 仅操作当前页可见记录，禁用项跳过，忙碌期间不能改变选择。
- 普通点击更新起点；有效的 Shift 点击保留起点，便于扩展区间。
- 翻页、排序和调整每页条数只清除 Shift 起点，保留已选记录；仓库、编号或状态筛选范围变化及取消选择时清空对应列表选择。两个列表互不影响。
- 自动刷新返回相同顺序时保留起点，记录顺序变化时下一次 Shift 点击按普通单选处理。只更新当前响应中可见的已选记录，不因其他页记录未出现而删除选择。
- 标题选择按钮与复选框支持键盘操作；子控件的 Enter/Space 不冒泡触发行详情。Shift 点击时选择区域不产生文字选中。
- 选择不提交任务；仍使用既有批量手动触发确认流程，不改变后端去重与调度。
- 提交时由既有后台接口重新校验目标，部分失败只保留失败记录供重试，全部成功清空选择；不因目标不在当前页而跳过。已选 MR/PR 刷新后不可触发时仍可取消勾选。

## 验证

覆盖正反向区间、整段取消、区间外保留、无起点、顺序更新、禁用项、两个列表隔离，以及实际复选框、标题与空白区域点击和键盘行为。补充真实不同页数据、全页数量、跨页批量请求、排序与条数调整保留、筛选清空、返回原页勾选及部分失败重试验证。
