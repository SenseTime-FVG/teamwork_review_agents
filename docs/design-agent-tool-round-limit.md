# Agent 模型与工具交互轮数上限

## 已确认范围

将自研模型运行器原来写死的 64 轮改为全局默认 256 轮。Agent 可单独覆盖，留空继承全局值；根 Agent 与子 Agent 各自计数。完整 Codex CLI 模式仍由 CLI 管理内部循环，不套用此配置。

不新增根任务 60 分钟总时限，不修改现有超时、取消、模型回退或上下文压缩策略。

## 计数与提醒

一轮是一次正常模型请求及其返回工具的执行。同轮多个工具仍算一轮；同轮模型回退和摘要请求不增加轮数，压缩也不重置计数。最后一轮直接返回最终答复时允许正常完成。

剩余 32 轮时记录一次可见提醒，并在最后这些请求中提供准确的剩余预算。若配置上限不足 32 轮，从第一轮提醒。提醒仅引导梳理覆盖范围、避免重复读取和优先完成必要工作，不要求省略验证或把未完成任务说成成功。提示作为当前请求的运行约束，不改写原始任务或持久对话。

## 耗尽终态

最后一轮工具执行完仍未完成时，记录独立错误码 `agent_tool_round_limit`，返回失败且 `retryable=false`。保留本轮累计用量、模型身份与日志，明确任务未完成；不再由事件调度器或 Agent 幂等重试入口自动从头执行。暂时性网络故障沿用现有策略，人工触发新任务仍是独立操作。

## 配置与展示

- `runtime.max_tool_rounds`：严格正整数，默认 256。
- `agents.<name>.max_tool_rounds`：可选严格正整数，空值继承全局。
- 全局及 Agent 管理表单显示配置入口；Agent 留空时明确显示当前继承的具体轮数。
- 选模请求日志和模型快照记录本轮上限及来源，提醒与耗尽事件采用中文说明。

## 验收

覆盖默认值、全局修改、Agent 覆盖及恢复继承、非法值拒绝、超过原 64 轮后成功、最后一轮正常完成、达到上限停止、提醒阈值、小上限、多工具同轮、回退与压缩不重置预算，以及耗尽后持久状态不允许自动重试。前端验证表单与日志展示，执行构建及相关回归。
