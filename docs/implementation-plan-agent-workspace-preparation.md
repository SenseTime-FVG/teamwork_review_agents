# Agent 工作区准备与仓库级依赖缓存实施方案

## 配置与兼容

- 新增仓库级 `AgentWorkspaceConfig` 和 `AgentWorkspacePrepareStepConfig`。
- 默认关闭缓存且准备步骤为空，保证旧配置行为不变。
- 校验相对工作目录和参数数组，运行时再次校验解析后的目录没有逃逸工作区。
- 保持现有 Preflight 缓存目录和环境变量兼容，增加通用缓存变量。

## 后端执行

- 扩展通用步骤执行器以支持每步工作目录和命令包装器。
- 在 Agent 工作区建立后、模型启动前执行仓库配置的准备步骤。
- 使用 Agent 联网策略和工作区可写权限生成外层沙盒命令，并只增加当前仓库缓存根目录写权限。
- 将缓存环境合并到准备命令和后续 Agent 进程环境，不进入 Prompt。
- 将阶段、步骤、输出和失败原因持续写入当前运行日志。

## 管理界面

- 扩展 TypeScript 仓库配置类型。
- 仓库详情新增准备区块、缓存开关和结构化步骤编辑器。
- 参数继续采用“执行程序 + 每行一个参数”，补充相对工作目录字段。
- 保持只读/编辑模式和现有仓库详情保存流程一致。

## 验证

- 配置模型：默认值、合法相对目录、绝对路径和目录逃逸拒绝。
- 缓存：同仓库跨分支共享、不同仓库隔离、通用变量兼容。
- 执行器：每步目录、直接参数执行、输出、失败、超时和取消。
- 沙盒：准备命令固定工作区可写、缓存目录精确放行、网络策略继承。
- Executor：准备成功才启动 Runner；失败时不启动并产生可读日志。
- UI：TypeScript 构建与仓库配置编辑器字段完整。
