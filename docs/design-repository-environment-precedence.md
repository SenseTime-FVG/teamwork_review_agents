# 仓库环境变量优先级设计

## 生效顺序

同名环境变量的优先级调整为：仓库 > Agent > 全局。Agent 提供跨仓库复用的默认值，仓库定义本次运行的环境差异。系统运行变量最后注入，仍不可覆盖。

覆盖单位是整个变量定义：值或宿主机引用来源、Secret、Prompt 暴露和进程暴露开关一起采用高优先级层的配置。仓库变量为空或宿主机引用缺失时使用空值，不自动回退到 Agent 或全局。Provider Token 继续强制按 Secret 脱敏。

## 保持不变

- 后台扫描及平台 API 的 Token 仍按仓库 > 全局 > 宿主机解析，不读取 Agent 配置。
- 不隶属 Agent 的仓库准备任务仍按仓库 > 全局解析。
- 子 Agent 使用自己的 Agent 配置和当前仓库配置，不继承父 Agent 的变量定义。
- 不迁移或修改用户 YAML；已有同名配置在新版运行中按新顺序生效。

## 验证与说明

同步更新全局、仓库及 Agent 配置页面和使用文档。测试覆盖三层同名覆盖、同一 Agent 在不同仓库运行、完整定义与空值覆盖、运行变量保护、子 Agent 及 Token 解析边界。所有测试使用临时配置与模拟值，不读取真实凭据。
