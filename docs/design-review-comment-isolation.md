# 通用审核的评论读取隔离设计

## 目标与范围

通用审核不读取历史评论和讨论正文，避免之前的自动审核结论影响当前独立判断。PR / MR 标题和描述仍是必要审核材料；GitHub 页面顶部的描述对应 `body`，GitLab 对应 `description`，不属于评论列表。

本次只修改 `prompts/general-review.md` 的行为约束，不改压缩机制、平台客户端、评论发布逻辑或任意命令执行权限，不自动覆盖自定义 Prompt。

## 读取边界

- 保留标题、描述、提交记录、完整 diff、相关代码、测试、配置和设计文档。
- 不读取人工或机器人顶层评论、旧自动审核结果、行内评审评论、评审意见正文及讨论线程；不保留按需读取人工讨论的例外。
- 不请求 `comments`、`notes`、讨论正文等字段或接口，也不通过 CLI 评论选项、网页 Conversation 或 Timeline 绕过该限制。
- 描述为空时如实记录，不使用第一条评论补全描述；按字段区分描述与评论，不按页面位置或评论序号区分。
- 查询意外附带的评论正文不作为审核证据、本轮执行事实或继续获取讨论的依据。

## 门禁和发布不变

继续查询审批是否满足、讨论是否已解决、CI、分支保护和可合并状态等必要元数据，不读取意见正文。无法可靠确认门禁时仍按原规则处理，不因禁止读评论而默认放行。

仍按现有规则发布本轮审核结果；存在 `publish_comment` 时必须使用该工具。评论查重和更新由既有发布机制负责，不要求模型读取历史评论。

## 生效方式与验证边界

文件型 Prompt 在构造新运行输入时读取。引用本模板的 Agent 在文件更新后的新运行中采用新约束；已构造的运行输入及自定义 Prompt 不自动改写。

回归测试验证自动合并、仅审核和默认模式的渲染契约，以及运行器确实把文件规则加入输入。测试不代表模型行为的绝对保证，本次也没有实现网络层硬拦截。
