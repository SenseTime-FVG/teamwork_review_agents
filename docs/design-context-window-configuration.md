# 分层上下文窗口配置

## 规则

所有层级使用可空的 `context_window_tokens`，单位为 token。留空表示继承，不把计算结果写回配置。

| 配置位置 | 未填写时 |
| --- | --- |
| Provider | 系统默认 272000 |
| 全局默认模型、全局回退项 | 该项 Provider 的窗口 |
| Agent 继承全局模型 | 全局默认模型的有效窗口 |
| Agent 显式选择 Provider | 所选 Provider 的窗口，即使它与全局 Provider 相同 |
| Agent 回退项 | 该项 Provider 的窗口 |

显式配置优先。界面同时展示具体数值与来源；模型候选切换时预算、运行快照同步切换。模型身份去重仍按 Provider / 模型执行，先出现的配置优先。

## 运行边界

窗口用于项目自建模型循环的预算，不向外部 API 添加非标准参数，也不把配置值当作上游模型能力承诺。停止读取 Codex 模型缓存中的窗口，避免隐藏覆盖。完整 CLI 模式仍由 CLI 自己管理上下文。

自动压缩阈值保持窗口的 95%，并受输出预留空间约束。系统指令及原始任务仍原样保留。窗口必须为整数、至少 2048，且大于输出预留与 512 的结构余量。

## 旧配置兼容

读取旧 `runtime.context_compaction.default_context_window_tokens` 时，把显式旧值迁移到尚未设置窗口的 Provider；旧 `model_context_windows` 迁移到当前已配置的全局模型、显式 Agent 模型和回退项。新字段（包括显式 null）优先。未被当前模型节点使用的旧覆盖归档在 `legacy_model_context_windows`，保留原值但不参与运行；以后启用这些模型需在界面显式配置。迁移在内存中完成，正常保存时落盘，不主动改写用户配置。
