# 仓库级 Skill 白名单实施方案

## 配置与运行时

1. 为 `RepositoryConfig` 增加可空的 `allowed_skills` 列表，默认使用空列表。
2. 增加统一的有效 Skill 计算函数，实现默认不限制、非空求交集和 `null` 全部禁止。
3. 校验仓库非空白名单中的 Skill 引用。
4. Codex CLI 与模型基座运行器统一使用有效 Skill 列表。
5. 将模型基座运行日志中的 Skill 数量调整为实际交集数量。

## 管理界面

1. 扩展仓库配置类型，支持 `string[] | null`。
2. 在仓库详情增加三态单选策略卡片。
3. 仅在“仅允许所选”状态展示 Skill 多选列表，并阻止空选择。
4. 新建仓库默认写入空列表，表示不额外限制。
5. Skill 重命名和删除时同步维护仓库引用，删除最后一个引用时转换为禁止所有。
