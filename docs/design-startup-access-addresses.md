# 启动时展示本机与局域网访问地址

## 已确认需求

服务监听 `0.0.0.0` 时，启动和重启除了监听地址，还应输出带端口的本机地址、各网卡候选地址以及管理员认证提示。只改变提示，不修改监听、管理员 Token 校验或防火墙。

## 实现

- 使用项目已有依赖 psutil 枚举已启用网卡；不进行 DNS 解析、外网探测或网络配置变更。
- IPv4 通配监听只列出 IPv4；IPv6 通配监听只列出 IPv6，使用方括号 URL，不假设 IPv4 双栈可达。
- 排除回环、未指定、多播与链路本地地址；候选去重并稳定排序，保留网卡名称。VPN、容器和 WSL 网卡无法统一识别，不伪称物理局域网地址，也不保证其他设备可达。
- 仅监听回环地址时不枚举局域网地址；指定具体地址或主机名时只展示指定端点，不虚构 `127.0.0.1` 可用。
- 无候选或网卡读取失败时保留本机提示，并说明未检测到候选；地址发现失败不能使已经启动的服务变成失败。
- `start`、`restart` 和已在运行的提示共用格式；`run` / `serve` 在 Uvicorn 真正就绪后输出相同提示，后台子进程也会写入后台日志。
- 认证提示只接收“是否配置管理员 Token”，不接收或输出 Token 值；直接调用后台管理函数未传该标记时，提示以实际服务配置为准。

## 验证边界

使用虚构网卡验证多网卡、重复地址、停用网卡、IPv4/IPv6、读取异常与指定监听地址。隔离子进程测试验证启动、重启、端口覆盖、就绪后输出和 Token 不泄漏。不重启当前真实服务。
