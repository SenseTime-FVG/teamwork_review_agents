# Agent 工作区依赖快照与预热实施方案

## 后端

- 扩展仓库级缓存模块，计算跨分支准备指纹、管理安全归档、持久化元数据并执行 LRU 清理。
- 扩展 Agent 工作区准备器：优先恢复快照，失败回退完整准备，成功后创建快照并写入工作区标记。
- Executor 在 sub-agent 继承父工作区时显式跳过重复准备，避免再次执行安装命令。
- 新增仓库手动预热管理器，使用默认分支临时 worktree 执行同一准备流程，并提供开始、状态和取消接口。
- 服务停止时取消仍在运行的预热任务并回收临时工作区。

## 前端

- 扩展仓库工作区准备状态类型和 API 调用。
- 在“Agent 工作区准备”标题区增加“预热准备”按钮。
- 只读模式下轮询当前仓库预热状态，展示快照命中状态、阶段、指纹、大小和最近完成时间。
- 准备中允许查看实时步骤与有界输出并取消；失败后允许重试。
- 更新缓存说明，明确下载缓存与可恢复依赖快照的区别。

## 兼容与安全

- `cache_enabled: false` 或没有 `prepare_steps` 时不计算、不恢复和不创建快照。
- 旧配置无需迁移；旧运行日志继续按原样展示。
- 归档创建只采集 Git 未跟踪/忽略文件，恢复时进行路径和链接边界校验。
- 快照损坏只造成缓存未命中，完整准备步骤仍可继续运行。

## 验证

- 指纹：同锁文件跨分支一致，锁文件、命令、平台或程序变化后失效。
- 快照：首次创建、再次恢复、损坏回退、路径逃逸拒绝和 LRU 清理。
- Executor：独立工作区命中快照；继承工作区跳过重复准备；失败仍不启动模型。
- 手动预热：默认分支检出、实时状态、取消、失败重试和服务关闭回收。
- UI：按钮状态、轮询、日志、只读/编辑模式和 TypeScript 构建。
