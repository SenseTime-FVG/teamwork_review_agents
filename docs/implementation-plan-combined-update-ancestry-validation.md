# 组合更新入口祖先校验实施方案

1. 在入口 Prompt 增加固定正向命令、变量来源、独立退出码捕获及异常分类，并补充最终报告的证据字段。
2. 从实际渲染的 Prompt 提取命令，在临时 Git 仓库构造双亲合并拓扑，验证目标前进、目标等于合并点、真实分叉、反向误判和对象缺失。
3. 将新回归测试加入 Windows 显式测试列表；测试不依赖 Bash，不访问业务仓库或远端。
4. 运行定向 Prompt、配置和上下文压缩测试，再运行 Python 全量测试，检查新增 Prompt 长度没有破坏既有预算测试。
5. 检查完整差异后按用户既有要求提交并推送当前分支。保留无关文件，不重新触发历史任务。
